# Fira Code

`FiraCode.ttf` is the Fira Code variable font distributed by Google Fonts:

https://github.com/google/fonts/tree/main/ofl/firacode

Downloaded on 2026-10-19 from:
`https://raw.githubusercontent.com/google/fonts/main/ofl/firacode/FiraCode%5Bwght%5D.ttf`

SHA-256: `9335b082b3c7850d98a64b584f3417f65355f3471278bb5eeb8c6c0e8657aeeb`

The binary is checked in so rendering does not depend on a mutable remote font
or fonts installed on the user's machine. Redistribution terms are in `OFL.txt`.
The shape atlas uses weight 400 and the font's default ligatures/contextual
alternates; the standard fixed and adaptive modes retain their original font.
